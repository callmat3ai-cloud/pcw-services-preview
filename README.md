# PCW Services - Premium General Contractor Website

This repository contains the premium, single-page responsive website built for **PCW Services (PCW Contracting Services)**, a leading general contractor in Southern California serving HOAs, commercial buildings, and residential estates since 1989.

## Features

- **Premium Modern Design**: Built with a sophisticated color palette (Navy `#0f172a`, Orange `#f97316`, Gold `#fbbf24`), clean typography (Bebas Neue for headings, DM Sans for body), smooth hover micro-animations, and organic wave SVG section dividers.
- **Responsive Layout**: Designed mobile-first, matching all screen sizes.
- **Scroll-Linked Animations**: Utilizes `IntersectionObserver` for smooth element fade-ins, and animated number counters for key company stats.
- **Interactive Service Directory**: Showcases 18 certified specialized services in a clean grid and list view, linking dynamically to a detail modal with service descriptions, highlights, and a call-to-action that pre-populates the contact form.
- **Interactive Filterable Projects**: Integrates category filters for residential, waterproofing, and commercial/HOA projects.
- **Interactive AI Chatbot UI**: A simulated AI assistant to answer frequent questions about licensing, services, quotes, and hours.
- **Pulsing WhatsApp Support**: Fast WhatsApp messaging redirect widget.
- **SEO & Local Schema Optimized**: Fully integrated SEO tags, social sharing metadata (OpenGraph & Twitter Card), and a JSON-LD LocalBusiness schema.

## Development & Viewing

Open the `index.html` file in any modern web browser or serve it using a local dev server.
